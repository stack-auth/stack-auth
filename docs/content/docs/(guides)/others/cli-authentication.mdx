If you're building a command line application that runs in a terminal, you can use Stack Auth to let your users log in to their accounts.

To do so, we provide a Python template that you can use as a starting point. [Download it here](https://github.com/stack-auth/stack-auth/tree/main/docs/public/stack-auth-cli-template.py) and copy it into your project, for example:

```py
└─ my-python-app
   ├─ main.py
   └─ stack_auth_cli_template.py  # <- the file you just downloaded (rename to use underscores for Python import)
```

Then, you can import the `prompt_cli_login` function:

```py
from stack_auth_cli_template import prompt_cli_login

# prompt the user to log in
refresh_token = prompt_cli_login(
  app_url="https://your-app-url.example.com",
  project_id="your-project-id-here",
  publishable_client_key="your-publishable-client-key-here",
)

if refresh_token is None:
  print("User cancelled the login process. Exiting")
  exit(1)

# you can also store the refresh token in a file, and only prompt the user to log in if the file doesn't exist

# you can now use the REST API with the refresh token
def stack_auth_request(method, endpoint, **kwargs):
  # ... see Stack Auth's Getting Started section to see how this function should look like
  # https://docs.stack-auth.com/python/getting-started/setup

def get_access_token(refresh_token):
  access_token_response = stack_auth_request(
    'post',
    '/api/v1/auth/sessions/current/refresh',
    headers={
      'x-stack-refresh-token': refresh_token,
    }
  )

  return access_token_response['access_token']

def get_user_object(access_token):
  return stack_auth_request(
    'get',
    '/api/v1/users/me',
    headers={
      'x-stack-access-token': access_token,
    }
  )

user = get_user_object(get_access_token(refresh_token))
print("The user is logged in as", user['display_name'] or user['primary_email'])
```

## Customizing the CLI Auth Confirmation Page

When users authenticate your CLI application, they're redirected to a browser page to confirm the authorization. Stack Auth provides this page at `/handler/cli-auth-confirm` by default, but you can create a custom page to match your application's design.

### Using the `useCliAuthConfirmation` Hook

The `useCliAuthConfirmation()` hook gives you everything you need to build a custom CLI auth confirmation page. It handles the protocol details internally, including reading the login code from the URL, managing authentication state, and completing the authorization.

```tsx title="app/cli-authorize/page.tsx"
'use client';
import { useCliAuthConfirmation } from "@stackframe/stack";

export default function CustomCliAuthConfirmPage() {
  const cliAuth = useCliAuthConfirmation();

  if (cliAuth.status === "invalid") {
    return (
      <div>
        <h1>Invalid CLI authorization link</h1>
        <p>This link is missing a login code. Please return to the CLI and try again.</p>
      </div>
    );
  }

  if (cliAuth.status === "success") {
    return (
      <div>
        <h1>CLI Authorized</h1>
        <p>You can close this window and return to the command line.</p>
      </div>
    );
  }

  if (cliAuth.status === "error") {
    return (
      <div>
        <h1>Authorization Failed</h1>
        <p>{cliAuth.error?.message}</p>
        <button onClick={cliAuth.retry}>Try again</button>
      </div>
    );
  }

  return (
    <div>
      <h1>Authorize CLI Application</h1>
      <p>A command line application is requesting access to your account.</p>
      <button onClick={cliAuth.authorize} disabled={cliAuth.isLoading}>
        {cliAuth.isLoading ? "Authorizing..." : "Authorize"}
      </button>
    </div>
  );
}
```

### Hook Return Values

The `useCliAuthConfirmation()` hook returns an object with:

| Property | Type | Description |
|----------|------|-------------|
| `status` | `"idle" \| "invalid" \| "authorizing" \| "redirecting" \| "success" \| "error"` | Current state of the authorization flow |
| `error` | `Error \| null` | Error object if status is `"error"` |
| `isLoading` | `boolean` | `true` when status is `"authorizing"` or `"redirecting"` |
| `authorize` | `() => Promise<void>` | Function to start the authorization process |
| `retry` | `() => void` | Function to reset the state and try again |

### Configuring the Custom URL

After creating your custom page, configure Stack Auth to use it:

```tsx title="stack/server.ts"
export const stackServerApp = new StackServerApp({
  // ...
  urls: {
    cliAuthConfirm: '/cli-authorize',
  }
});
```

Users will now be redirected to your custom page when authorizing CLI applications.
