Examples for custom password reset pages. Users arrive here from the link in their reset email, usually with a `code` query parameter.

Configure your custom URL in [Custom Pages](/guides/other/customization/custom-pages).

## Custom page with `PasswordReset` component

The `PasswordReset` component provides a complete form with validation and error handling:

```tsx title="app/reset-password/page.tsx"
"use client";

import { PasswordReset } from "@hexclave/next";

export default function DefaultPasswordReset() {
  return <PasswordReset />;
}
```

## Integration with application routing

1. Create a route that handles the reset link (for example `/reset-password?code=xyz123`).
2. Pass the code to your component if you build a custom form.
3. Point Hexclave at your route:

```tsx title="stack/server.ts"
import { HexclaveServerApp } from "@hexclave/next";

export const hexclaveServerApp = new HexclaveServerApp({
  // ...
  urls: {
    passwordReset: { type: "custom", url: "/reset-password", version: 1 },
  },
});
```

Password reset emails will link to your custom page.

## Custom password reset form

For full UI control, build your own form. The `code` comes from the URL query string — Hexclave includes it in the reset email link.

```tsx title="app/reset-password/page.tsx"
"use client";

import { useHexclaveApp } from "@hexclave/next";
import { useState } from "react";

export default function CustomPasswordResetForm({ code }: { code: string }) {
  const [password, setPassword] = useState("");
  const [confirmPassword, setConfirmPassword] = useState("");
  const [error, setError] = useState("");
  const [success, setSuccess] = useState(false);
  const app = useHexclaveApp();

  const onSubmit = async () => {
    if (password !== confirmPassword) {
      setError("Passwords do not match");
      return;
    }

    const result = await app.resetPassword({ password, code });
    if (result.status === "error") {
      setError(result.error.humanReadableMessage);
      return;
    }
    setSuccess(true);
  };

  if (success) {
    return <div>Password successfully reset!</div>;
  }

  return (
    <form onSubmit={(e) => { e.preventDefault(); onSubmit(); }}>
      {error && <div>{error}</div>}
      <div>
        <label htmlFor="password">New password</label>
        <input
          id="password"
          type="password"
          value={password}
          onChange={(e) => setPassword(e.target.value)}
        />
      </div>
      <div>
        <label htmlFor="confirm">Confirm password</label>
        <input
          id="confirm"
          type="password"
          value={confirmPassword}
          onChange={(e) => setConfirmPassword(e.target.value)}
        />
      </div>
      <button type="submit">Reset password</button>
    </form>
  );
}
```
