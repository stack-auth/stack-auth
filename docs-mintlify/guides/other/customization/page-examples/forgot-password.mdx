Examples for custom forgot-password pages where users request a password reset email.

Configure your custom URL in [Custom Pages](/guides/other/customization/custom-pages).

## Custom page with `ForgotPassword` component

The `ForgotPassword` component renders a form to request a reset email:

```tsx title="app/forgot-password/page.tsx"
"use client";

import { ForgotPassword } from "@hexclave/next";

export default function DefaultForgotPassword() {
  return <ForgotPassword />;
}
```

## Integration with application routing

1. Create a route (for example `/forgot-password`).
2. Point Hexclave at your route:

```tsx title="stack/server.ts"
import { HexclaveServerApp } from "@hexclave/next";

export const hexclaveServerApp = new HexclaveServerApp({
  // ...
  urls: {
    forgotPassword: { type: "custom", url: "/forgot-password", version: 1 },
  },
});
```

Links to the forgot-password flow use your custom page. After submission, Hexclave sends an email linking to your [password reset](/guides/other/customization/page-examples/password-reset) page.

## Custom forgot password form

```tsx title="app/forgot-password/page.tsx"
"use client";

import { useHexclaveApp } from "@hexclave/next";
import { useState } from "react";

export default function CustomForgotPasswordForm() {
  const [email, setEmail] = useState("");
  const [error, setError] = useState("");
  const [message, setMessage] = useState("");
  const app = useHexclaveApp();

  const onSubmit = async () => {
    if (!email) {
      setError("Please enter your email address");
      setMessage("");
      return;
    }

    const result = await app.sendForgotPasswordEmail(email);
    if (result.status === "error") {
      if (result.error.errorCode === "USER_NOT_FOUND") {
        // Do not reveal whether the account exists.
        setError("");
        setMessage("If an account exists with this email, a password reset link has been sent.");
      } else {
        setError(result.error.humanReadableMessage);
        setMessage("");
      }
    } else {
      setError("");
      setMessage("Password reset email sent! Please check your inbox.");
    }
  };

  return (
    <form onSubmit={(e) => { e.preventDefault(); onSubmit(); }}>
      {error && <div>{error}</div>}
      {message ? (
        <div>{message}</div>
      ) : (
        <>
          <input
            type="email"
            placeholder="email@example.com"
            value={email}
            onChange={(e) => setEmail(e.target.value)}
          />
          <button type="submit">Send reset link</button>
        </>
      )}
    </form>
  );
}
```

See [Known Errors](/guides/other/known-errors) for other `sendForgotPasswordEmail` error codes.
