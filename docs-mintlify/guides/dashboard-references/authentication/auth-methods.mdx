## Sign-up card

- **Allow new user sign-ups** (`auth.allowSignUp`) — confirm dialogs when enabling/disabling

- **Same-email social login policy** dropdown (`auth.oauth.accountMergeStrategy`): Link accounts / Create new account / Block sign-up
